# KageriEditor 開発メモ

日本語の文書作成を主な目的とした、macOS ネイティブ（Swift + AppKit）のプレーンテキストエディタです。
Xcode プロジェクトは不要で、コマンドライン（swiftc）だけでビルドできます。

利用者向けの紹介は [README.md](../README.md)、配布相手向けの説明書は
[はじめにお読みください.txt](はじめにお読みください.txt) を参照してください。

## ビルドと起動

```sh
./build.sh
open "build/KageriEditor.app"
```

コマンドラインツール（`xcode-select --install`）が入っていればビルドできます。
`build.sh` は arm64 と x86_64 を別々にコンパイルして `lipo` で結合し、
ユニバーサルバイナリを `build/KageriEditor.app` に生成します（アドホック署名まで行います）。

## テストの実行

`Tests/test.swift` は `TextLogic.swift` の純粋ロジック（文字数カウント・整形・非整形・
空行除去・原稿用紙換算・ファイル名生成）を検証します。

```sh
TEST_DIR=$(mktemp -d)
cp Tests/test.swift "$TEST_DIR/main.swift"   # エントリポイントは main.swift という名前である必要がある
swiftc -o "$TEST_DIR/run_tests" Sources/TextLogic.swift "$TEST_DIR/main.swift"
"$TEST_DIR/run_tests"
```

`make_dist.sh` はこのテストを最初に実行し、失敗したら配布物を作らずに中断します。

## 配布

```sh
./make_dist.sh
```

テスト → クリーンビルド → zip 化まで自動で行い、`dist/KageriEditor-<バージョン>.zip` を生成します。
中身は `KageriEditor.app` と `はじめにお読みください.txt` の2点で、この zip を渡すだけで配布できます。
バージョン番号は `Info.plist` の `CFBundleShortVersionString` から取られます。

## 画面の構成

ウインドウは上から順に次の3段です。

1. **メニューバー**（`MenuBarView`）— カスタマイズ可能なボタン列。右端に「⋮」のプルダウン
2. **本文**（`NSTextView` + 行番号ルーラー + 文字数の目盛り）
3. **ステータスバー** — 左に「行数｜字数｜原稿用紙の枚数」、右に自動保存の間隔・
   文字コード・改行コードのポップアップと「編集／閲覧」ボタン

使用頻度の低い項目はメニューバーに置かず、右端「⋮」のプルダウンにまとめています
（別名保存／ファイル名変更／印刷／保存せず閉じる／閲覧モード／設定／使い方）。
これらは macOS 標準のメニューバー（画面上部）からも従来どおり使えます。

## キーボードショートカット

アプリ内では ⌃/ でも一覧を表示できます（`showShortcutHelp`）。

| 操作 | キー |
|---|---|
| 新規 / 開く / 履歴 | ⌃N / ⌃O / ⌃D |
| メモ（quickmemo.txt を開く） | ⌘⌥M |
| クリップボードからメモに追記 | ⌘⇧M |
| 保存 / 別名保存 / ファイル名変更 | ⌃S（⌘S）/ ⌃G（⌘⇧S）/ ⌃T |
| 閉じる / 保存せず閉じる | ⌃W（⌘W）/ ⌃Q |
| 取り消す / やり直す | ⌘Z / ⌃Y（⌘⇧Z） |
| 検索 / 検索と置換 / 検索結果一覧 | ⌃F（⌘F）/ ⌘⌥F / ⌘⇧F |
| 非整形 / 整形 | ⌃R / ⌃E |
| 空行除去 / スペース除去 | ⌃L / ⌃K |
| 閲覧モードの切替 | ⌃B |
| 日付 / 時刻を挿入 | ⌃; / ⌃⇧; |
| 設定 | ⌃I（⌘,） |

⌃ 系のうち非整形・整形・空行除去・スペース除去・ファイル名変更・保存せず閉じるは、
Shift を押したままでも動くよう、非表示の複製メニュー項目（⌃⇧R など）でも受けています。

## 主な機能の仕様

### 保存（⌘S）

- **初回保存時のみ**、本文の中で最初に文字がある行の先頭から **全角換算 20 文字**
  （半角は 0.5 換算）までを取り出し、`.txt` を付けてファイル名にします。
- ファイル名に使えない `/` と `:` は全角に置き換え、制御文字と先頭のドットを取り除きます。
  文字がある行が一つもなければ「無題」になります。
- 保存先は設定で指定したフォルダです（未設定時は `~/Documents`）。
  同名ファイルがある場合は「名前 2.txt」のように番号を付けます。
- **一度ファイル名が付いたら、以後はリネームしません。** ⌘S も自動保存も同じファイルへの
  上書き保存になります（1行目を書き換えても名前は変わりません）。
- 名前や場所を変えたいときは「別名保存」、名前だけ変えたいときは「ファイル名変更」を使います。

### 自動保存

- 既定は **オフ（0分）** です。設定、またはステータスバーの「自動保存」ポップアップで
  オフ／1／3／5／10／30分から選べます（設定画面では 0〜120 分の任意の値を指定でき、
  その値もポップアップの選択肢に加わります）。
- 変更がないとき、日本語入力の変換中、一度も保存していない空の文書のときは何もしません。

### 保存の安全装置

- **外部変更の検出** — 他の端末やアプリがファイルを書き換えていた場合、上書き前に確認します。
  検出中は自動保存を止め、ステータスバーに理由を表示します。
- **大幅変更ガード** — 前回保存時より本文が大幅に減っている（空になった、8割以上減った）
  場合は操作ミスの可能性があるため、自動保存を一時停止して確認します。
  ただしメモ（quickmemo.txt）は書き溜めては消す使い方をするため対象外です。
- **リネームの追従** — 他の端末でファイル名が変わっていた場合、記録を辿って追従します。

### 文字数・原稿用紙の枚数

- 文字数は全角を 1、半角を 0.5 として数えます。改行は数えません。
  ○●■□▲▼★☆※→↑↓× などの記号は日本語文中では全角1文字として扱います。
- 原稿用紙の枚数は **400字詰め（20字×20行）の行単位** で数えます。出版社や公募と同じ
  数え方で、段落の途中で改行すると行末の余白もマスとして消費します（空行も1行）。
  端数は小数第1位で切り捨てるため、「1枚」と表示されていれば1枚分書けています
  （改行のない文章なら381字で20行目に入り1枚）。

### 整形・非整形・空行除去・スペース除去

4つとも選択範囲（なければ文書全体）が対象で、**選択が行の途中から始まっても・
途中で終わっても、その行全体を選択したものとして行単位で処理します**
（`TextTransform.expandToWholeLines`）。

- **非整形（⌃R）** — 改行を取り除きます。行頭が全角スペース・括弧類・箇条書き記号
  （・ ● ○ ◎ ■ □ ◆ ◇）・丸付き数字（①〜㊿、❶〜➓ など）の行は段落の先頭とみなし、
  その直前の改行を残します。空行も段落区切りとして残します。
  設定の「段落を区別しない」を有効にすると、記号による段落判定を行わず空行だけを残します。
- **整形（⌃E）** — 設定した全角換算の文字数（既定 40 字）で改行を挿入します。
  句読点・閉じ括弧・小書き文字・長音符などが行頭に来る場合は前の行の末尾にぶら下げます
  （ぶら下げが2文字続いたら、3文字目以降は強制的に改行します）。
- **空行除去（⌃L）** — 改行だけの行を取り除きます。連続する空行は1回につき1行だけ減るので、
  繰り返し実行して好みの行あけで止められます（3行あけ→2行あけ→1行あけ→詰める）。
- **スペース除去（⌃K）** — 設定で選んだ全角／半角スペースを取り除きます（既定はどちらもオン）。
  全角スペースを除去する場合も、段落の字下げにあたる行頭の全角スペースは残します
  （「段落を区別しない」が有効なときは行頭も除去します）。

実行後は選択が解除され、カーソルは対象の先頭（文書全体に実行した場合は元の位置）に置かれます。

### メモ

- ⌘⌥M で保存フォルダ内の `quickmemo.txt` を開きます（⌘M は macOS 標準の
  「ウインドウをしまう」と衝突するため ⌘⌥M）。ファイルが無ければ空で自動生成します。
- ⌘⇧M でクリップボードの内容を日時付きでメモの末尾に追記します。
- `Info.plist` の `NSServices` に「メモに追記」を登録しており、他アプリの選択文字列から
  サービスメニュー経由で追記できます。**ただし Developer ID による署名・公証がないと
  一部アプリのサービス一覧に出ません**（アドホック署名では Gatekeeper に弾かれるため）。
  ⌘⇧M のクリップボード経由が実用上の代替になります。

### 閲覧モード（⌃B）

読み返しに専念するためのモードです。入力とカーソルを止め（文字の選択とコピーは可能）、
文字数の目盛りを隠します。メニューバーは薄く表示したまま残すので、
ステータスバーの位置は変わりません。設定として保存せず、起動のたびに解除状態から始まります。

### タブ

`window.tabbingMode = .preferred` により macOS 標準のウインドウタブを使っています
（`.automatic` はシステム設定「タブ付きウインドウを優先」に従うため、通常ウインドウでは効きません）。
新しいウインドウは画面に出る前に既存のタブグループへ合流させ、既存ウインドウがあれば
その位置とサイズを引き継ぎます（あとから合流させると一瞬ちらついて見えるため）。
設定でオフにすると、まとまっていたタブを個別のウインドウへ分離します。

### その他

- 日本語の文書作成向けに、スマート引用符・スペル自動修正などの自動置換はすべて無効です。
- 文字コード（UTF-8 / Shift-JIS）と改行コード（LF / CRLF）はステータスバーのポップアップで
  切り替えます。開くときは自動判別します。Shift-JIS で表現できない文字を含む場合は
  保存時にエラーで知らせます。
- 改行を「↩」、全角スペースを「□」としてグレーで表示します（フォーマット > 改行・全角スペースを表示）。
- ダークモードは端末に従う／ライト／ダークから選べます（設定）。
- 行番号は画面での折り返しを含めた「表示行」で数えます。ただしステータスバーの行数は
  改行の数（物理行）です。文書全体の正確な表示行数を毎回数えるとレイアウトが強制的に走り、
  大きな文書で重くなる（過去にクラッシュの原因になった）ため、あえて分けています。

## ファイル構成

- `Sources/TextLogic.swift` — 全角換算カウント・原稿用紙換算・整形／非整形・空行除去・
  スペース除去・選択範囲の行単位への拡張・ファイル名生成の純粋ロジック（テスト対象）
- `Sources/main.swift` — エディタ本体（NSDocument / NSTextView / 行番号ルーラー /
  文字数の目盛り / ステータスバー / メニュー / 設定パネル）
- `Sources/ToolbarMenu.swift` — 日付・時刻の書式、メニューバー（`MenuBarView`）と
  その並び替えエディタ
- `Sources/DocumentSafety.swift` — ハッシュ計算（`DocumentSafety`）、リネームの記録と解決
  （`RenameJournal`）、最近開いたファイルの履歴とカーソル位置（`RecentHistory`）。
  外部変更の検出・大幅変更ガードの判定そのものは `main.swift` の `Document` にある
- `Sources/SearchMatchList.swift` — 検索結果一覧
- `Tests/test.swift` — ロジックのテスト
- `Resources/AppIcon.icns` — アプリアイコン（`swift scripts/make_icon.swift` で再生成）
- `scripts/make_icon.swift` — アイコン生成（Mac の icns、Android の mipmap PNG、
  Google Play 用 512px を一括生成）
- `scripts/make_feature_graphic.swift` — Google Play のフィーチャーグラフィック生成
- `docs/はじめにお読みください.txt` — 配布相手向けの説明書
- `docs/DEVELOPMENT.md` — このファイル
- `build.sh` — ビルドスクリプト（ユニバーサルバイナリを生成）
- `make_dist.sh` — 配布用 zip の作成スクリプト
